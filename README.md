# Waze User Churn EDA

Exploratory data analysis of Waze user data for a user churn project, done in Python as part of a Coursera data course.

## Notebook

* `waze_eda.ipynb`: cleaning, visualizing and summarizing user behavior in the Waze dataset

## Tools

Python, pandas, numpy, seaborn, matplotlib, Jupyter Notebook

## Data

The notebook reads `waze_dataset.csv`, provided in the course. The file is not included in this repository.
